# FORMA — Kurumsal İş Kıyafetleri Demosu

Next.js (App Router), TypeScript ve Tailwind CSS ile hazırlanmış kurumsal tanıtım ve dijital ürün kataloğu.

## Çalıştırma

```bash
cd website
npm install
npm run dev
```

Tarayıcıda `http://localhost:3000` adresini açın.

## Güncellenecek alanlar

- Firma adı, telefon, e-posta, adres, WhatsApp ve harita: `data/company.ts`
- Ürünler: `data/products.ts`
- Sektör metinleri: `data/sectors.ts`

## Not

Site e-ticaret içermez. İletişim formu demo modundadır; gerçek mesaj gönderilmez.
